# 모델 테스트 요약 (Mask-aware Advective Graph + GRU)

## 1) 문서 목적

사용자 제공 PDF `Mask-aware Advective Graph + GRU_테스트결과.pdf` 내용을
프로젝트 문서 체계(`docs/`)에 맞춰 요약 정리한 문서입니다.

## 2) 모델 설명(원문 요약)

- 모델 명칭: `Hydro-MAST`
- 구조 요약: `Mask-aware Advective Graph + GRU`
- 핵심 아이디어:
  - 그래프(Advective Graph): 상류->하류 전파 관계를 반영
  - GRU: 시간 흐름(시계열 의존성) 학습
  - Mask-aware: 결측/노이즈 구간에 대한 강건성 확보
- 다중 시점 예측: 1시간, 3시간, 6시간(원문 기준)

## 4) 해석 메모

- 2025-09는 전반적으로 양호(특히 1시간/3시간).
- 2025-10은 전 시점 성능 하락(NSE 저하, 오차 증가).
- 2025-11은 3시간/6시간 성능 회복.
- 2025-12는 RMSE/MAE가 작지만 NSE는 중간 수준으로, 분산/구간 특성까지 함께 봐야 함.

## 5) 데이터 신뢰성 주의사항

- PDF 텍스트 추출 시 일부 월/시점 표기가 중복 또는 비정상적으로 보이는 구간이 있어,
  본 문서는 **원문 기록값 보존**에 우선순위를 두었습니다.
- 최종 발표/보고서 반영 시에는 `validate_hydro_mast.py` 산출물(`docs/hydro_mast_metrics.json`)
  또는 원본 시계열 그래프와 교차 검증 후 확정하는 것을 권장합니다.
