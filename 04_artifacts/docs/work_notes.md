## 2. 새 전처리 v2 — 어떻게 적용했는가

### 2-1. 전체 흐름

```
yeoju 원천 CSV
    ↓ 병합·결측·이상치·피처(lag·시간·차분)
    ↓ MinMax (2024~2025 2년 fit)
features_v2_train.csv (2년) / features_v2_test.csv (말미 10%, 지표용)
```

실행: `preprocess_v2.py`

### 2-2. ① 병합

- K-water 일별 10분 파일을 모두 읽어 `시간` 축으로 합침
- HRFC 관측소별 파일을 wide 형태로 pivot (예: `hrfc_1007639_수위_m` = 여주보 상류)
- 10분 간격 공통 그리드에 left join → **105,264행** (2024~2025)

### 2-3. ② 결측·이상치 (논문 + yeoju handoff)

| 변수 종류 | 규칙 | 근거 |
|-----------|------|------|
| 강우·유입·방류 | 결측 → **0** | CNN-GRU(2023): 강우 결측 0 |
| 수위·댐수위 | **IQR clip (k=1.5)** → 선형보간(최대 6스텝=1시간) → ffill(최대 18스텝=3시간) | yeoju handoff + 다변량 Spline 개념 |
| 강우 | IQR clip **안 함** (호우 피크 보존) | yeoju handoff |

### 2-4. ③ 피처 엔지니어링

| 피처 | 내용 | 근거 |
|------|------|------|
| 시간 부호화 | sin/cos(시각), sin/cos(연중일) | 다변량 시계열(2024) |
| 1차 차분 | 주요 수위·강우·방류의 `diff1` | 다변량(2024) |
| Lag | 6, 18, 36, 72스텝 (= 1h, 3h, 6h, 12h) | 기존 파이프라인 + 다변량 |
| 예측 타깃 | `target_수위_m` = HRFC **1007639** (여주보 상류) | — |
| 6시간 후 타깃 | `target_수위_m_h36` = 36스텝 뒤 수위 | CNN-GRU(2023) 6시간 예측 |

총 **72개 입력 피처** (스펙: `preprocess_v2_spec.json`)

### 2-5. ④ 정규화·분할

- **MinMaxScaler(0~1)**: **2024~2025 2년 전체**로 fit (준비한 학습 데이터 전부 사용)
- `features_v2_train.csv`: 2024-01-01 ~ 2025-12-31 (약 10.5만 행)
- `features_v2_test.csv`: 위 구간 **말미 10%** — 모델 학습에는 쓰지 않고 NSE 등 지표만 계산
- 예측 1회 입력: 해당 시각 + **직전 12시간** lag (2년 통째 입력 아님)

### 2-6. 기존 AI팀 전처리와 차이

| 항목 | AI팀 (예전) | v2 (이번) |
|------|-------------|-----------|
| 원본 | HRFC 24관측 통합본 | yeoju kwater+HRFC 재병합 |
| 이상치 | interpolate + fillna(0) 혼재 | 수위 IQR + 역할별 결측 정책 |
| 스케일 | 전체 fit | train만 fit |
| 입력 수 | 24 + lag 20 | 72 (17관측소 wide) |

## 3. AI 모델 — Hydro-MAST (2년 학습)

### 3-1. 개요

- **Hydro-MAST**: 17 HRFC + 댐 노드 **하천 그래프**, 간선 **학습 지연 전파**, **GRU** 공유 코어
- **단기·장기 동시**: 10분 / 1h / 3h / 6h (h1, h6, h18, h36)
- **추론 입력**: 예측 시각 **직전 12시간(72스텝)** 관측만 사용 (2년 통째 입력 아님)
- 학습 데이터: `features_v2_train.csv` **전체 2년**

### 3-2. 학습·실행

| 단계 | 파일 |
|------|------|
| 전처리 | `preprocess_v2.py` → `features_v2_train.csv` (2년) |
| 학습 | `train_hydro_mast.py` → `hydro_mast_v2.pt` |
| 발표 | `open_present.bat` → `present_server.py` |

### 3-3. 성능 (holdout 10%)

| 시점 | NSE |
|------|-----|
| 1시간 후 | 0.924 |
| **6시간 후** | **0.868** |

- 상세: `docs/hydro_mast_metrics.json`
- 보조자료(사용자 제공 테스트 PDF 요약): `docs/모델테스트_요약_2025하반기.md`
- 학습: 2년 전체, stride=2(20분 간격 샘플·속도 최적화), 마스킹 견고 학습

### 3-4. 아직 없는 것 (홍수 “예방”)

- 경보 단계 자동 판정, 대피 연동, 임계수위 규칙 → **별도 운영 설계** 필요  
- 본 패키지는 **예측 모델 + 전처리 데이터**까지
